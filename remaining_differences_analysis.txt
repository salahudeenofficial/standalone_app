### Potential Causes:

#### 1. **Input Data Differences**
- **Motion Pipeline**: Uses dummy/constant control video data
- **ComfyUI**: Uses real video data with natural variation
- **Impact**: Different input distributions lead to different latent distributions

#### 2. **VAE Model Differences**
- **Motion Pipeline**: Uses motion pipeline's WAN VAE implementation
- **ComfyUI**: Uses ComfyUI's WAN VAE implementation
- **Impact**: Different model weights or architecture variations

#### 3. **Preprocessing Differences**
- **Motion Pipeline**: Custom preprocessing pipeline
- **ComfyUI**: ComfyUI's native preprocessing
- **Impact**: Different input normalization or tensor transformations

#### 4. **process_input Function Differences**
- **Motion Pipeline**: `lambda image: image * 2.0 - 1.0`
- **ComfyUI**: Same function but may have different input ranges
- **Impact**: Different input ranges to VAE encoder

#### 5. **Tensor Format Differences**
- **Motion Pipeline**: Converts to `[1, 3, T, H, W]` format
- **ComfyUI**: May use different tensor format internally
- **Impact**: Different tensor layouts affect VAE processing
