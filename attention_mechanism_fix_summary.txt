ATTENTION MECHANISM FIX SUMMARY
==============================

PROBLEM IDENTIFIED:
==================
The vae_attention() function in Motion Pipeline was calling functions directly instead of via model_management module like ComfyUI, causing different attention mechanisms to be selected.

BEFORE (Motion Pipeline):
```python
def vae_attention():
    if xformers_enabled_vae():  # Direct call
        return xformers_attention
    elif pytorch_attention_enabled_vae():  # Direct call
        return pytorch_attention
    else:
        return normal_attention
```

AFTER (Fixed to match ComfyUI):
```python
def vae_attention():
    if model_management.xformers_enabled_vae():  # Via module
        return xformers_attention
    elif model_management.pytorch_attention_enabled_vae():  # Via module
        return pytorch_attention
    else:
        return normal_attention
```

CHANGES MADE:

1. Fixed vae_attention() function calls:
   - Changed xformers_enabled_vae() → model_management.xformers_enabled_vae()
   - Changed pytorch_attention_enabled_vae() → model_management.pytorch_attention_enabled_vae()

   - Changed from ...model_management import * → import model_management
