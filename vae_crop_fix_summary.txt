# VAE vae_encode_crop_pixels Bug Fix Summary

## Issue Identified
The motion pipeline's `vae_encode_crop_pixels` function in `standalone_vae.py` was incorrectly cropping tensor dimensions, which caused empty tensors and a `RuntimeError: min() arg is an empty sequence` error.

## Root Cause
For 5D input tensors `[B, C, T, H, W]`, the function was using:
```python
dims = pixels.shape[1:-1]  # [C, T, H] - INCLUDES channel dimension (BUG)
```

This caused the function to crop the channel dimension (C), which should never be cropped, leading to empty tensors.

## ComfyUI Reference Implementation
ComfyUI's version correctly excludes batch and channel dimensions:
```python
def vae_encode_crop_pixels(self, pixels):
    downscale_ratio = self.spacial_compression_encode()
    
    dims = pixels.shape[1:-1]  # For 4D [B, H, W, C]: gets [H, W]
    for d in range(len(dims)):
        x = (dims[d] // downscale_ratio) * downscale_ratio
        x_offset = (dims[d] % downscale_ratio) // 2
        if x != dims[d]:
            pixels = pixels.narrow(d + 1, x_offset, x)
    return pixels
```

ComfyUI's VAE expects 4D input `[B, H, W, C]` and crops spatial dimensions `[H, W]` only.

## Motion Pipeline Fix
Updated `standalone_vae.py` to handle both 5D and 4D inputs correctly:
```python
def vae_encode_crop_pixels(self, pixels):
    """Crop pixels to be divisible by downscale ratio"""
    downscale_ratio = self.spacial_compression_encode()
    
    # For 5D input [B, C, T, H, W], we want spatial dims [T, H, W]
    # For 4D input [B, H, W, C], we want spatial dims [H, W]
    if pixels.ndim == 5:  # [B, C, T, H, W]
        dims = pixels.shape[2:]  # [T, H, W] - spatial dimensions only
        start_dim = 2  # Start from dimension 2 (T)
    else:  # [B, H, W, C] or similar
        dims = pixels.shape[1:-1]  # [H, W] - spatial dimensions only
        start_dim = 1  # Start from dimension 1 (H)
    
    for d in range(len(dims)):
        x = (dims[d] // downscale_ratio) * downscale_ratio
        x_offset = (dims[d] % downscale_ratio) // 2
        if x != dims[d]:
            pixels = pixels.narrow(start_dim + d, x_offset, x)
    return pixels
```

## Key Differences
1. **ComfyUI**: Processes 4D tensors `[B, H, W, C]` where channels are last
2. **Motion Pipeline**: Processes 5D tensors `[B, C, T, H, W]` where channels are second
3. **Fix**: Detects tensor dimensionality and extracts only spatial dimensions for cropping
