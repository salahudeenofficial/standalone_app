FUNCTION 2: model_management.free_memory()
===============================================================================

PURPOSE:
- Intelligently unloads models to free GPU memory
- Prioritizes unloading based on memory usage and reference count
- Calls garbage collection and cache clearing
- Returns list of unloaded models for tracking

WHAT IT DOES:
1. Identifies models that can be safely unloaded
2. Calculates memory that will be freed
3. Unloads models using model_unload() method
4. Calls soft_empty_cache() to clear PyTorch cache
5. Handles different VRAM states (LOW_VRAM, NORMAL_VRAM, etc.)
